# SpendSmart

SpendSmart is a full-stack personal budgeting application for tracking expenses, managing monthly budgets, and understanding spending habits.

The project also includes a local AI financial coach that can answer questions about a user's spending using read-only application tools. Financial values are calculated by the application rather than generated by the language model.

## Features

- Create and manage monthly budgets
- Track expenses by category
- Set category spending limits
- View monthly spending summaries
- Monitor remaining budget and category usage
- Interactive React dashboard
- AI financial coach powered locally through Ollama
- Read-only tool calling for grounded financial responses
- MCP support for exposing the same financial tools through a standard interface
- PostgreSQL persistence with database migrations

## Architecture

SpendSmart separates the application into frontend, API, service, repository, and database layers.

```text
React Frontend
      |
      | HTTP / JSON
      v
FastAPI Backend
      |
      v
Service Layer
      |
      v
Repository Layer
      |
      v
PostgreSQL
```

The AI coach uses the same application services through a restricted tool layer:

```text
User Question
      |
      v
AI Coach
      |
      | tool request
      v
Read-Only Tools
      |
      v
Application Services
      |
      v
PostgreSQL
```

The model does not receive direct database access. Financial calculations such as totals, remaining budget, percentages, and category limits are computed by application code and returned to the model as structured data.

## AI Coach

The financial coach is designed to keep AI-generated responses grounded in application data.

The implementation:

- restricts the model to an allow-list of financial tools
- exposes financial data through read-only operations
- validates tool arguments before execution
- limits conversation history and tool-call rounds
- performs financial arithmetic in application code
- prevents clients from supplying system or tool messages
- treats tool results as data rather than instructions

Ollama is used so the AI functionality can run locally without requiring a paid external AI API.

## Running Locally

### Prerequisites

- Python 3
- Node.js
- PostgreSQL or Docker
- Ollama if using the AI coach

Clone the repository:

```bash
git clone https://github.com/oali1029/spendsmart.git
cd spendsmart
```

Create your local environment file from the provided example and choose your own database password:

```bash
cp .env.example .env
```

Start PostgreSQL:

```bash
docker compose up -d
```

### Backend

```bash
cd backend

python -m venv .venv
```

Activate the virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Run the database migrations:

```bash
alembic upgrade head
```

Start the API:

```bash
uvicorn app.main:app --reload --port 8010
```

### AI Coach

Install and start Ollama, then make sure the model configured in `.env` is available locally.

The application supports direct in-process tools as well as an MCP-based tool provider.

### Frontend

From the frontend directory:

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Testing

Backend tests are located in `backend/tests`.

```bash
cd backend
pytest
```

The tests cover the core budgeting functionality as well as the AI tool layer, model integration, summaries, and MCP behavior.

## Project Goals

SpendSmart started as a budgeting application and evolved into an experiment in integrating language models with structured application data safely.

A major design goal was to keep the database and financial calculations authoritative while using the language model primarily for natural-language interaction. This keeps deterministic financial logic in normal application code while still allowing users to ask conversational questions about their spending.
